# English AI Tutor — MVP 0.2

Нативное iOS-приложение на SwiftUI для ежедневной 10-минутной голосовой практики английского с подготовкой к работе бортпроводником.

## Реализовано в 0.2

- Голосовой ввод английской речи через Apple Speech.
- Запись оригинального аудио в CAF-файл внутри Application Support на iPhone.
- Возможность воспроизвести последнюю оригинальную запись.
- Отключена автоматическая пунктуация Apple Speech; задача распознавания установлена в `.unspecified`.
- Ожидание финального результата распознавания перед отправкой реплики Claude (до 2,5 секунды после остановки микрофона).
- Голосовой ответ через AVSpeechSynthesizer; выбирается один из доступных английских голосов по списку предпочтительных женских имён, затем используется системный en-US fallback.
- Загрузка доступных моделей из `GET /v1/models` Router.cheap.
- Выбор модели из каталога; при первом подключении предлагается Claude Sonnet, если он есть в списке, иначе другая Claude-модель, затем первая доступная.
- Проверка соединения с API и показ количества моделей.
- Запросы к `/v1/chat/completions` с выбранной моделью.
- Исправление до двух важных ошибок на русском после ответа, без перебивания.
- Таймер урока на 10 минут; незавершённый урок можно продолжить после повторного запуска приложения.
- Сохранение истории уроков локально в JSON в Application Support.
- API-ключ хранится в iOS Keychain.

## Важное ограничение распознавания

Apple Speech не предоставляет приложению режим гарантированной дословной фонетической транскрипции. Отключение пунктуации и `.unspecified` уменьшают лишнее оформление, но движок всё равно может выбрать неверные слова или нормализовать сказанное. Поэтому оригинальная аудиозапись сохраняется отдельно, а в интерфейсе есть её воспроизведение. В этой версии оригинальное аудио **не отправляется в Claude** и автоматическая фонетическая оценка ещё не реализована.

Для надёжной проверки произношения следующим этапом нужно добавить отдельный ASR/аудиоанализ, который принимает аудиофайл и сверяет фактические звуки, а не только текст Apple Speech.

## Настройка

1. Открой `EnglishAITutor.xcodeproj` в Xcode на Mac.
2. В Target → Signing & Capabilities выбери Apple Development Team.
3. При необходимости измени Bundle Identifier.
4. Запусти приложение на iPhone и разреши доступ к микрофону и распознаванию речи.
5. Открой Settings → введи API key Router.cheap → Save API key securely.
6. Нажми **Check connection and load models**.
7. Выбери Claude Sonnet (кнопка Use recommended Claude model) или любую модель из каталога.
8. Нажми Done и начни урок кнопкой Tap to speak.

API base URL по умолчанию: `https://router.cheap/v1`. Можно указать `https://router.cheap` — приложение само добавит `/v1`.

## Сборка IPA

1. Открой проект в Xcode.
2. Выбери физический iPhone или Any iOS Device (arm64).
3. Выбери личную команду подписи в Signing & Capabilities.
4. Product → Archive.
5. Для sideload установки используй экспорт Development/Ad Hoc, совместимый с твоей подписью, или установи собранный `.app` через Sideloadly.

## Безопасность и расходы

Ключ не вшит в Swift-файлы и хранится в Keychain. Но приложение вызывает Router.cheap прямо с iPhone, поэтому ключ доступен приложению на самом устройстве. Для публичного распространения нужен backend-прокси. Каждый ответ модели расходует баланс Router.cheap; начни с коротких уроков и модели Sonnet/Haiku, если важна стоимость.
